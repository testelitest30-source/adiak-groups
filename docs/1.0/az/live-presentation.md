# Canlı təqdimat

Təqdimatı açıb **Canlını aç** basın. Sinif ekranında **Proyektor görünüşü**ndən istifadə edin.

**Səhnə**: indi çıxış edən komanda və natiq, böyük taymer (son dəqiqədə narıncı, vaxt keçəndə qırmızı), qeydə alınmış müddətlərlə bütün sıra, növbəti komanda və təsdiqlənmiş final (PDF, ox düymələri, tam ekran).

**Operator paneli**: Canlı sessiyanı başlat (komandalar və sıralar dondurulur) · Fasilə / Davam et · Komandanı bitir (vaxt qeydə alınır) · Növbəti komanda · Əvvəlki komanda (qeydə alınmış vaxt davam edir) · Komandanı keç · Növbəti / əvvəlki natiq · Vaxt düzəlişi (səbəblə) · Sessiyanı bitir · Gizli qeydlər · Qiymətləndirmə.

Taymer serverdədir: yeniləmə, bağlantının kəsilməsi, cihaz dəyişmək və ya telefonun arxa plana keçməsi vaxtı itirmir.
