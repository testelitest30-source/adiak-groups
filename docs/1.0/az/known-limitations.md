# Məhdudiyyətlər və problemlərin həlli

* **PPTX/Keynote canlı baxışda göstərilmir** — finalı PDF yükləyin; digər formatlar yeni pəncərədə açılır.
* **Veb push** (brauzer bağlı olanda sayt bildirişi) 1.1 versiyasındadır.
* **Tətbiq ikonu** şəffaf fonda qaradır (sahibin seçimi) — tünd divar kağızında çətin görünür.
* Planlı xatırlatmalar və push təkrarları üçün **pg_cron** aktiv olmalıdır.
* Davamiyyət uçotu yoxdur.
* "Çox sürətli" mesajı — bir dəqiqə gözləyin · push gəlmir → İdarəetmə Mərkəzi → Çatdırılma · yeniləmədən sonra köhnə ekran → səhifəni yeniləyin.
