# Android quraşdırma

1. GitHub Release-dən `ADIAK-v1.0.0.apk` faylını yükləyin.
2. Telefonda açın; Android soruşanda "Naməlum tətbiqləri quraşdır" icazəsini verin.
3. **ADIAK**-ı açın və ID/parolunuzla daxil olun.
4. Soruşulanda **bildirişlərə icazə verin**.
5. Yeniləmə: yeni APK-nı köhnənin üzərinə quraşdırın (eyni imza — məlumatlar qalır).
