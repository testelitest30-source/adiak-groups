# Tələbə bələdçisi

* **Təqdimatlar** — hər təqdimat üçün komandanızın iş sahəsi:
  * *İcmal*: son tarix, püşkdən sonra komandanızın sırası, hazırlıq dairəsi, elanlar.
  * *Çıxış sırası*: boş yeri seçin (komanda göndərənə qədər dəyişə bilərsiniz). Hamı seçəndə istənilən üzv göndərir; host və ya müəllim təsdiqləyir.
  * *Fayllar*: qaralamaları yükləyin (PDF, PPTX, DOCX, şəkil, video… 25 MB-a qədər). **Final kimi göndər**; müəllim təsdiqləyir və ya qeydlə qaytarır. Təsdiqlənmiş final kilidlənir. Finalı **PDF** yükləyin ki, canlı ekranda açılsın.
  * *Tapşırıqlar*, *Komanda çatı* (hər təqdimatın öz çatı var), *Rəy* (müəllim dərc edəndən sonra).
* **Sinif işləri** — sinif elanları və tapşırıqlar; fayl və/və ya qeyd göndərin, müəllimin rəyini görün.
* **Bildirişlər** — serverdə saxlanılır, bütün cihazlarda eynidir; toxunanda müvafiq ekran açılır.
