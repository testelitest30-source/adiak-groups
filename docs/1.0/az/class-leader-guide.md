# Sinif nümayəndəsi bələdçisi (Sinif Mərkəzi)

**Sinif Mərkəzi** sinfinizi göstərir: tələbələr, komandalar (üzv / tutum), komandasız tələbələr, yaxınlaşan son tarixlər.
* **announce** icazəsi ilə sinif elanı yaza bilərsiniz.
* **report** icazəsi ilə müəllimlərə problem bildirə və cavabı izləyə bilərsiniz.
Qiymətləndirmə, parollar, ayarlar və başqa siniflər sizə açıq deyil.
