# ADIAK 1.0.0

**ADIAK 1.0** — sinif komandalarının yaradılması, əməkdaşlıq və təqdimatlar üçün vahid platforma (veb sayt və Android tətbiqi).

## Yeniliklər
- **Komanda Təqdimat Mərkəzi** — ədalətli püşkatma, çıxış sırası, tapşırıqlar, son tarixlər, fayllar və kilidlənən FINAL versiya, komanda söhbəti.
- **Canlı Təqdimat** — proyektor görünüşü, serverlə sinxron taymer, çıxış edənin izlənməsi, PDF təqdimat, qiymətləndirmə meyarları (vaxt meyarı daxil).
- **Müəllim Studiyası** — siniflərin idarəsi, tapşırıqlar, elanlar, yoxlamalar və hesabatlar.
- **Sinif Mərkəzi** — sinif rəhbəri üçün elanlar, komanda koordinasiyası və müəllimə müraciət.
- **Bildirişlər** — tətbiqdaxili bildiriş mərkəzi və Android push bildirişləri (tətbiq bağlı olanda belə).
- **İdarəetmə Mərkəzi** — əməliyyatlar, çatdırılma, audit, platforma tənzimləmələri və diaqnostika.
- **Yeni ADIAK loqosu** və açılış animasiyası.

## Düzəlişlər və təhlükəsizlik
- Mesajların silinməsi düzəldildi; Android-də səsli mesaj üçün mikrofon icazəsi düzəldildi.
- Verilənlər bazası təhlükəsizliyi gücləndirildi (icazələr, sürət məhdudiyyəti, audit); qeydiyyat yalnız dəvətlə.
