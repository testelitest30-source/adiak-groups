# Android installation

1. Download `ADIAK-v1.0.0.apk` from the GitHub Release (or the Actions artifact).
2. Open it on the phone; allow "Install unknown apps" for your browser/files app when Android asks.
3. Open **ADIAK**, sign in with your ID and password.
4. When asked, **allow notifications** (deadlines, approvals, your turn to present, messages).
5. Updates: install the newer APK over the old one (same signing key — your data stays).

Check the installed version: Menu → Settings shows the build (version · commit · run).
