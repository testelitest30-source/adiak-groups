# Teacher guide (Teacher Studio)

After signing in you land in **Teacher Studio**: a greeting, your classes with what is waiting (reviews, speaking orders, issues), the next deadline or presentation and quick actions. Choose a class with the **class switcher**; ADIAK remembers it.

## Run a presentation
1. **Presentations → New presentation**: title, description, start time, final deadline, minutes per team.
2. Tick the **participating teams**, then **Open for teams**. Students now see the workspace.
3. **Run the draw** — the order is drawn on the server and shown with an animation. Redrawing or changing teams afterwards needs a reason and keeps the history.
4. Follow preparation in **Overview**: speaking order (approve / return), final file (open, approve, or return with a note), tasks.
5. **Change deadline** (with reason) re-times the 24 h / 2 h reminders automatically.
6. Build the **rubric** (criteria, max, weight; optional *time management* criterion with target and tolerance).
7. **Open live** on the classroom screen (see the Live guide). Score teams in the operator console; **Publish feedback** when ready.

## Assignments, announcements, issues
* **Assignments**: create (individual or team, deadline, files allowed), publish, review submissions (accept / request changes with feedback), see who is missing, close or reopen.
* **Announcements**: post (optionally pinned) — students are notified.
* **Issues**: reports from the class representative; acknowledge or resolve with a reply.
