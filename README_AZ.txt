ADIAK Team Maker — oxunaqlı kod paketi

Fayllar:
  index.html  — əsas saytın HTML quruluşu
  styles.css  — əsas saytın görünüşü (CSS)
  app.js      — əsas saytın JavaScript funksiyaları
  admin.html  — idarəetmə panelinin HTML quruluşu
  admin.css   — admin panelinin görünüşü
  admin.js    — admin panelinin JavaScript funksiyaları

Necə açmaq olar:
  1. ZIP faylını çıxart.
  2. Bütün faylları eyni qovluqda saxla.
  3. Əsas sayt üçün index.html, admin paneli üçün admin.html aç.
  4. HTML, CSS və JS fayllarını bir-birindən ayırma.

Qeyd:
  - Mövcud davranışları dəyişdirmək məqsədi ilə yeni funksiyalar yazılmayıb.
  - Kod fayllara bölünüb və oxunaqlılıq üçün formatlanıb.
  - Supabase/CDN istifadə edildiyinə görə internet bağlantısı tələb oluna bilər.
  - Əvvəlki faylları ehtiyat nüsxə kimi saxla.
